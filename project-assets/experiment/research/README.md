# Research Archive

Rohdaten und Quellen für das KI-Brand-Experiment.

## Struktur

```
research/
├── session-1/       # First Principles, Logic Tree
├── session-2/       # Kategorie-Analyse
├── session-3/       # AI-Native Deep Dive
├── session-4/       # Discover Finale, Trust Research
└── sources.md       # Master-Liste aller Quellen
```

## Quellen-Typen

- **Perplexity Outputs** — Vollständige Antworten mit Citations
- **Web Sources** — Artikel, Studien, Reports
- **Competitor Analysis** — Screenshots, Positioning-Analysen
- **Data Points** — Statistiken mit Quellenangabe

## Qualitätsstandard

Jede Behauptung in den Session-Dokumenten sollte hier eine Quelle haben.
