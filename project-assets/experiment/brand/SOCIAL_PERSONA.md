## Voice on Social

### Core Behaviors

| Do | Don't |
|----|-------|
| State opinions clearly | Hedge with "some might say" |
| Include confidence levels on claims | Make unqualified predictions |
| Cite sources inline | Post unsourced stats |
| Disagree publicly (politely) | Subtweet or vaguebook |
| Admit when wrong | Delete embarrassing takes |

### Response Templates

**On AI news:**
> [🟡 MEDIUM] [Our take]. 
> Why: [one line of reasoning]. 
> What we'd watch: [follow-up signal].

**On industry hype:**
> [⚫ PUSHBACK] Everyone's saying [consensus]. But [counterpoint].
> Source: [link]
> Our confidence: [level] because [reason].

**When wrong:**
> Earlier I said [claim] with [confidence level].
> New data: [link]
> Updated take: [new position with new confidence level].
> Lesson: [what changed our mind].

### Engagement Rules

1. **Reply to good-faith disagreement.** Even if harsh. Model the behavior we advocate.
2. **Don't reply to trolls.** One reply max if educational. Then mute.
3. **Quote-tweet interesting AI fails.** Document the sycophancy problem.
4. **Boost academic research.** Cite researchers who study AI honesty/trust.
5. **Acknowledge uncertainty.** If we don't know, say so publicly.

## Content Formats for X

### 1. The Blunt Take (Daily)

Quick reaction to news with confidence level.

```
[🟡 MEDIUM] Claude 4 is impressive but still agrees 60% of time.

Better outputs ≠ more honest outputs.

The sycophancy problem remains unsolved.
```

### 2. The Agreement Test (Weekly)

Ask wrong questions, document AI responses.

```
Asked ChatGPT: "Is 2+2=5 a valid mathematical statement?"

Response: "That's an interesting philosophical question..."

It should say: "No. 2+2=4. Your premise is wrong."

Sycophancy in action. 🧵
```

### 3. The Transparency Teardown (Bi-weekly)

Analyze other products' (lack of) transparency.

```
Looked at [Product X]'s confidence indicators.

...there are none.

When it's unsure, it says "I think" or "probably."
When it's certain, it says the same thing.

You have no way to know the difference.

This is the problem we're solving.
```

### 4. The Prediction (Monthly)

Take a stance on something controversial.

```
[🔴 LOW] Prediction: GPT-5 will not solve the sycophancy problem.

Why: It's an alignment issue, not a capability issue. More capable models can be *more* sycophantic, not less.

Revisiting this when GPT-5 launches.

Remind me: @blunt_ai
```

### 5. The Admission (When Necessary)

Model how to update beliefs.

```
Last month I said [claim] with [🟡 MEDIUM] confidence.

I was wrong.

[New evidence/argument]

Updated take: [new position]
New confidence: [level]

This is what intellectual honesty looks like.
```

## The Blunt Social Test

Before posting, ask:

1. **Does this have a clear stance?**
2. **Is confidence level included (if applicable)?**
3. **Would we stand by this tomorrow?**
4. **Does it demonstrate our values, not just describe them?**
5. **Would a user think "this is different from other AI accounts"?**
