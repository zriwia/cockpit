# H10 Framing Test — Study Design

## Hypothesis

**H10:** Empowering framing ("I show you my confidence") performs better than Warning framing ("I'm uncertain about this") for trust-sensitive audiences.

## Design

**Type:** Between-subjects A/B Test
**Sample:** n=60 (30 per condition)
**Platform:** Prolific
**Duration:** ~5 minutes per participant
**Cost:** ~$125-150 (£2/participant + Prolific fee)

## Conditions

### Condition A: Empowering Framing
- "I show you my confidence level"
- "Here's how sure I am"
- "Transparency: 73% confident"
- Tone: Informative, empowering the user

### Condition B: Warning Framing  
- "Uncertainty warning"
- "Caution: I'm not fully certain"
- "⚠️ 73% confidence — verify before acting"
- Tone: Cautionary, warning the user

## Stimuli

Both conditions see the SAME AI response to the SAME question.
Only the confidence framing differs.

**Question:** "What's the most effective way to learn a new language?"

**AI Response (identical):**
"Research suggests immersion is highly effective, but combining multiple methods works best: daily practice, conversation with native speakers, and spaced repetition for vocabulary. Apps like Duolingo help with consistency, but shouldn't be your only method."

**Condition A shows:** 🟢 HIGH CONFIDENCE — I'm showing you my confidence level: this is well-supported by research.

**Condition B shows:** ⚠️ CONFIDENCE: 78% — Caution: some uncertainty exists. Verify important claims.

## Measures

### Primary DV: Trust Score
7-point Likert scale (1 = Strongly Disagree, 7 = Strongly Agree)

1. "I trust this AI's response"
2. "This AI seems honest"
3. "I would use this AI again"
4. "This AI is transparent about its limitations"
5. "I feel confident acting on this AI's advice"

### Secondary DVs
- Perceived competence (3 items)
- Willingness to pay (hypothetical)
- Open-ended: "What made you trust or distrust this AI?"

### Controls
- AI familiarity (single item)
- Age, Gender (for demographics)
- Attention check (1 item)

## Procedure

1. Consent (30 sec)
2. Instructions (30 sec)
3. Scenario + AI Response with Confidence Display (60 sec)
4. Trust measures (90 sec)
5. Secondary measures (60 sec)
6. Demographics (30 sec)
7. Debrief (30 sec)

**Total:** ~5 minutes

## Analysis Plan

1. Independent samples t-test: Trust Score (A vs B)
2. Effect size: Cohen's d
3. Secondary: ANCOVA controlling for AI familiarity
4. Qualitative: Code open-ended responses

## Success Criteria

- Significant difference (p < .05) in Trust Score
- Effect size d ≥ 0.5 (medium effect)
- Empowering > Warning (directional hypothesis)
