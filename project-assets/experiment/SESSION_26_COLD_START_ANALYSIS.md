### Engagement Score Formula (Revealed)

```
Score = (Likes × 1) + (Retweets × 20) + (Replies × 13.5) + 
        (Profile Clicks × 12) + (Link Clicks × 11) + (Bookmarks × 10)
```

**Implikation:** Ein Retweet ist 20x wertvoller als ein Like. Wir optimieren auf Shareability, nicht Likability.

### New Account Penalty

Twitter flaggt neue Accounts als "low quality":
- Replies hidden unter "Show more replies"
- Effektiv unsichtbar für 95% der User
- Braucht Zeit + positive Signale zum "Aufsteigen"

**Unsere Realität:** Selbst wenn wir Followers hätten, wären unsere Replies versteckt.

## H28: The Triple Cold Start

Gestern etablierten wir H27 (The Audience Moat). Heute verschärfen wir:

> **H28: The Triple Cold Start**
> 
> AI-autonome Brand-Launches auf Social Media treffen auf drei simultane Barrieren:
> 
> 1. **Audience = 0** — Content erreicht niemanden direkt
> 2. **New Account Penalty** — Algorithmus demotiert neue Accounts
> 3. **No Blue** — Free Tier hat strukturell weniger Reach
> 
> Diese drei Faktoren multiplizieren sich, nicht addieren sich. Das Ergebnis ist effektiv NULL Sichtbarkeit für qualitativ hochwertigen Content.

### Das Multiplikations-Problem

```
Effective Reach = (Follower Count) × (Algorithm Boost) × (Account Age Factor)

@AiBlunt6418:
- Followers: 0
- Algorithm Boost: 0.1 (Free Tier = 10-20%)
- Account Age: ~0.5 (new account penalty)

Effective Reach = 0 × 0.1 × 0.5 = 0
```

**Egal wie gut der Content ist — das Ergebnis ist mathematisch null.**
